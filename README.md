# Hushållsbudget v12.4.4 (fullrestore + stabil delning)

**Återställning:** Fullt UI (dashboard, sektioner, delning, audit, år) + fixen som hindrar fokus från att hoppa när du skriver eget belopp i delningen. Budgetläge är **default OFF** och månad+år visas i headern.

## Publicera
1. Skapa repo (t.ex. `budget-pwa-v12.4.4`).
2. Lägg upp allt i `main`.
3. Settings → Pages → Source = **GitHub Actions**.
4. Efter deploy: **Hard refresh** (Ctrl+F5 / Cmd+Shift+R) om cache håller kvar äldre version.
