# Hushållsbudget v10 – Samlad release

**Innehåll:**
- **Huvudpersoner i Inkomster**: "Du" + valfria betalare som kort **bredvid varandra** längst upp. Lön matas per person.
- **Egna kategorier** med **samma layout** + **auto‑ikon**, placeras direkt under basraderna.
- **Dölj** basrader (👁️) — ignoreras i beräkningar.
- **🔗 Delning** på rader (fasta + rörliga) **proportionellt mot lön**.
- **Rad‑chips**: varje delad rad visar **belopp per person** i kr.
- **Fördelning per person**: visar **andel (%)**, **skall (kr)**, **betalat (kr)**, **progress (%)** och **saldo (kr)**.
- Dashboard (diagram + progress), CSV/PDF, dark mode, tips, gamification.
- PWA/offline.

## Publicera
1. Skapa repo (t.ex. `budget-pwa-v10`).
2. Ladda upp allt till `main`.
3. Settings → Pages → Source = **GitHub Actions**.
4. URL: `https://<ditt‑användarnamn>.github.io/budget-pwa-v10/`.
